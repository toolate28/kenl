## ⚡ Quick Commands

### Install Server
```powershell
cd setup
.\Setup.ps1
```

### Start Server
```batch
.\scripts\Start-Server.bat
```

### Backup Server
```powershell
.\scripts\Backup-Server.ps1 -ServerPath "C:\MinecraftServer"
```

### Monitor Server
```powershell
.\scripts\Monitor-Server.ps1 -ServerPath "C:\MinecraftServer"
```
