## 🚀 How to Use

### Quick Start (First Time Setup)

```powershell
cd claudenpc-server-suite\setup
.\Setup.ps1
```

### Installation Flow

1. **Setup.ps1** loads core modules
2. **Configuration** gathered or loaded
3. **Preflight** checks validate environment
4. **Java** installation or verification
5. **PaperMC** server setup
6. **Plugins** installation
7. **Configuration** finalization
8. **Complete** - Server ready to start!

### Post-Installation

```powershell
# Start server
cd <ServerPath>
.\start.bat

# Or use utility script
cd claudenpc-server-suite\scripts
.\Start-Server.bat

# Backup server
.\Backup-Server.ps1 -ServerPath "C:\MinecraftServer"

# Monitor server
.\Monitor-Server.ps1 -ServerPath "C:\MinecraftServer"
```
