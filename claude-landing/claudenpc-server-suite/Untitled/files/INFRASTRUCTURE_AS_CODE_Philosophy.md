## Five IaC Principles Embedded in the Museum

### 1. **Explicit Specification** (No Hidden Behavior)

Traditional teaching: "Here's a concept. Trust me."
- Hidden mechanism: How does learning actually happen?
- Black box: You can't see inside the process
- Untraceable: Why did the kid learn or not learn?

**Safe Spiral approach:**
- Every Redstone block specified at exact coordinates
- Every comparator logic documented
- Every repeater timing explained
- **Zero hidden behavior**

A kid sees: X=400, Y=64, Z=500. Hopper at this position does this. Comparator measures this. Signal goes here.

**The child can trace every bit of information flow.**

This is radical compared to traditional pedagogy where learning happens in the "black box" of the student's mind.

### 2. **Reproducibility** (Build Once, Deploy Everywhere)

Traditional teaching: "Here's a lesson plan. Good luck with your students."
- Each classroom implementation is different
- Results vary unpredictably
- What worked with one group might fail with another

**Safe Spiral approach:**
```
EXHIBIT 1 SPECIFICATION:
Coordinate: X=95, Y=64, Z=100 [Lever block]
Power: Redstone signal flowing from this block
Routes to: X=99, Y=64, Z=101 [Repeater, 1-tick]
Connects to: X=111, Y=64, Z=100 [Comparator, comparison mode]
Outcome: Signal fires when switch activated

BUILD THIS IN ANY MINECRAFT WORLD.
RESULT IS IDENTICAL EVERY TIME.
```

The circuit works the same in Melbourne as Tokyo as rural Kansas.

**This is reproducible pedagogy.**

### 3. **Version Control & Evolution** (Gitops for Learning)

Traditional teaching: Textbooks freeze knowledge at publication time.

**Safe Spiral approach:** GitHub repository
```
/redstone-museum/
├─ exhibits/
│  ├─ exhibit-1-light-bulb/
│  │  ├─ v1.0/ (Initial design)
│  │  ├─ v1.1/ (Fixed timing issue)
│  │  ├─ v2.0/ (Simplified for younger kids)
│  │  └─ v2.1/ (Added accessibility features)
│  ├─ exhibit-2-double-sixes/
│  └─ ...
├─ facilitation-guides/
│  ├─ v1.0/
│  ├─ v1.1/
│  └─ v2.0/ (Refined based on teacher feedback)
├─ research-data/
│  └─ outcomes-2025.csv
└─ CHANGELOG.md
```

**Every improvement is tracked. Every version is available. Every change is reasoned.**

Kids can learn from v1.0 (original) or v2.1 (optimized for their age). Teachers can contribute improvements. Researchers can audit the evolution.

This is **living documentation**. Not "finished" knowledge, but evolving infrastructure that improves through use.

### 4. **Traceability** (Audit Trail of Learning)

Traditional teaching: "Did the kid learn? Let's give a test."
- Single snapshot of knowledge
- No visibility into learning process
- Can't see where confusion happened

**Safe Spiral approach:**

**Data collection at every step:**
```
EXHIBIT 3 CALIBRATION BOOTH:

Trial 1:
- Player prediction: Path B
- Player confidence: 12/15
- Actual answer: Path D
- Result: Wrong
- Player score this round: -(15-12) = -3 points
- Player observation: "I was more confident than I should have been"

Trial 2:
- Player prediction: Path A
- Player confidence: 8/15
- Actual answer: Path A
- Result: Correct
- Player score this round: +8 points
- Player observation: "I was less confident than I deserved to be"

[After 20 trials, complete audit trail shows learning trajectory]
```

**Every decision is logged. Every mistake is visible. Every insight is traceable.**

An educator can see: "Round 7, the player suddenly lowered their confidence claims. Why? What did they learn at that moment?"

### 5. **Composability** (Building Blocks That Snap Together)

Traditional pedagogy: Each lesson is isolated.
- Exhibit 1 doesn't connect to Exhibit 2
- Learning doesn't accumulate
- Kids can't build on previous understanding

**Safe Spiral approach:**

```
INFORMATION ARCHITECTURE STACK:

Layer 1: Light Bulb (Hidden State)
└─ Principle: Not everything is visible

Layer 2: Double Sixes (Randomness & Pattern)
└─ Principle: Invisible things still have structure
└─ Builds on: Layer 1 (hidden state → hidden structure)

Layer 3: Calibration Booth (Uncertainty Quantification)
└─ Principle: We can measure the invisible
└─ Builds on: Layers 1-2 (structure emerges from hidden randomness)

Layer 4: The Reroller (Strategy & Optimization)
└─ Principle: Optimal strategies emerge from measured uncertainty
└─ Builds on: Layers 1-3 (optimize what we can measure)

Layer 5: Bid-Ask Spread (Information Asymmetry in Systems)
└─ Principle: Systems coordinate through prices
└─ Builds on: Layers 1-4 (all five principles working together)
```

Each exhibit is a **composable module** that layers on previous learning.

A kid who understands Exhibit 1 is ready for Exhibit 2. Someone who mastered 1-4 can tackle 5.

**You can also use individual exhibits in different contexts:**
- Just teach calibration? Use Exhibit 3 alone.
- Just teach probability? Use Exhibit 2 alone.
- Want the full AI literacy arc? Run all five in sequence.

## Why This Matters for AI Ethics

The fundamental problem with AI is **opacity.**

Neural networks make decisions. We don't know how.
Algorithms optimize. We don't know what for.
Systems coordinate. We don't know by what mechanism.

**Result:** Trust disappears. Misalignment happens. Harm occurs.

The Safe Spiral Museum proves there's an alternative: **Make intelligence visible.**

Every principle the museum teaches—calibration, transparency, constraint reveals structure, information asymmetry—is foundational to ethical AI.

When a child learns calibration in Exhibit 3, they're learning why AI systems should output confidence scores, not just predictions.

When they learn information asymmetry in Exhibit 5, they're learning why transparency matters in markets, hiring, and governance.

**This museum IS embedded ethical AI infrastructure.**
