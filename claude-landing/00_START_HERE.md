# 🏙️ GitLab City - Complete Package

## 🎯 What Is This?

**GitLab City** is a revolutionary multi-tenant SaaS platform that visualizes Git repositories as explorable Minecraft buildings with AI-powered NPCs that explain your code.

```
Your Repository          →    Minecraft Building
├── src/                 →    Floor 1-20: Source code
│   ├── api/             →    API Research Lab
│   └── ui/              →    UI Design Studio
├── tests/               →    Floor 21-30: Testing chambers
└── docs/                →    Documentation library

Your Contributors        →    AI NPCs (powered by Claude)
├── Developer 1          →    NPC explaining their PR
├── Developer 2          →    NPC reviewing code
└── CI Bot               →    NPC showing test results
```

## 🎯 The Big Idea

### The Problem
- GitHub repos are hard to understand
- New developers get lost in code
- No spatial understanding of architecture
- Contribution feels invisible

### The Solution
- **Visualize** repos as 3D buildings
- **Explore** code spatially in Minecraft
- **Talk** to AI NPCs about the code
- **Reward** contributors with prestige plots

### The Magic
```
1. Connect GitHub repo
   ↓
2. Building generates automatically
   ├─ Size based on codebase
   ├─ Layout mirrors directory structure
   ├─ NPCs represent contributors
   └─ Updates in real-time
   ↓
3. Walk through your code
   ├─ Each floor = directory
   ├─ Talk to NPCs about files
   ├─ See CI/CD status live
   └─ Understand architecture spatially
   ↓
4. Contribute & Earn Access
   └─ Open source contributions → Penthouse plot!
```

## 🛠️ Tech Stack

```
Minecraft:
  ├─ PaperMC 1.21.3       (optimized server)
  ├─ Citizens             (NPC framework)
  ├─ Multiverse-Core      (multi-world)
  ├─ WorldEdit            (building generation)
  └─ ClaudeNPC            (AI integration)

Backend:
  ├─ Node.js + Express    (webhook server)
  ├─ PostgreSQL           (database)
  ├─ Socket.IO            (real-time)
  └─ Octokit              (GitHub API)

AI:
  └─ Anthropic Claude API (Sonnet 4)

Development:
  ├─ Java 25              (plugin development)
  ├─ Gradle               (build system)
  ├─ IntelliJ IDEA        (IDE)
  └─ Claude Code          (AI pair programming)
```
